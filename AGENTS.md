# AGENTS.md

Guidance for AI agents working in this repository.

## General Guidelines:
- Always ask clarifying questions when in doubt. Do not spend too much time planning when something unclear could be resolved by asking the user. Synthesis your clarification questions in a big question set.
- Never implement features yourself, always use subagents.
- Identify changes from the plan which can be implemented in parallel and use different subagents to do it.
